# 📊 Sales & Profit Dashboard

A beginner-friendly **Data Analytics Dashboard** created using Microsoft Excel to analyze sales and profit performance.

## 📌 Project Overview

This project focuses on analyzing sales data to understand business performance across different **categories, sub-categories, products, customers, states, and time periods**.

The dashboard provides a simple visual way to explore important sales and profitability trends and identify areas of strong and weak performance.

## 📂 Dataset

The dataset contains **8,314 sales records** with information including:

* Order Date
* Customer Name
* State
* Category
* Sub-Category
* Product Name
* Sales
* Quantity
* Profit
* Month
* Year

## 📈 Dashboard Analysis

The dashboard focuses on:

* 💰 **Total Sales**
* 📈 **Total Profit**
* 📦 **Quantity Sold**
* 🗂️ **Category & Sub-Category Performance**
* 📍 **State-wise Sales & Profit**
* 📅 **Monthly and Yearly Trends**
* 👤 **Customer Performance**
* 🛍️ **Product Performance**

## 🛠️ Tools Used

* **Microsoft Excel**
* Pivot Tables
* Excel Charts
* Data Analysis
* Dashboard Design

## 🎯 Key Objective

The main objective of this project was to practice **data cleaning, data analysis, pivot tables, visualization, and dashboard creation** using Excel.
